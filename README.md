# valorant-rank-checker

I got tired of opening the game just to check if I climbed. This fetches my current competitive rank and last few matches from Riot's API and dumps them in the terminal.

## install

pip install -r requirements.txt

## usage

The tool caches responses in ~/.cache/valorant-rank-checker/ to avoid hammering the API. Delete that directory if you want fresh data.
